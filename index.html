客户端选择与官方下载

小机场不绑定单一 App，订阅可在主流加速器中使用。请按下表匹配系统，优先选择仍在维护的版本，再导入订阅链接。下载入口在本页以锚点给出，安装完成后回到操作说明完成配置。

桌面端

  • Windows：Clash Verge 或 v2rayN。适合需要系统代理与规则分流的日常办公。官方下载见 Windows 客户端。
  • macOS：ClashX Meta 或 Surge。菜单栏可快速切换节点。官方下载见 macOS 客户端。
  • Linux：Clash Meta 命令行或兼容 GUI。适合服务器与开发环境。说明见 操作说明。

移动端

  • iOS / iPadOS：Shadowrocket 或 Stash。在应用内粘贴订阅，开启 VPN 配置。商店入口见 iOS 客户端。
  • Android：Clash Meta for Android。可配合分应用代理。官方下载见 Android 客户端。

客户端选择建议：新手用 Clash 系图形界面；需要精细分流与脚本用 Surge；只求手机出网用 Shadowrocket。导入后先测延迟，再固定一条常用节点，避免频繁自动切换造成会话中断。

使用场景

跨境会议与文档

远程会议、云文档与代码仓库访问时，选择延迟较低的邻近节点，并开启规则模式让国内站点直连。基础版即可覆盖三台常用设备；若同时开电脑与两部手机，建议旗舰版以免挤占在线名额。

流媒体与公开资讯

旗舰版强调全节点原生流媒体解锁，适合需要稳定片源与字幕轨道的观看需求。播放前切换到标注解锁的节点，关闭全局模式中不必要的 UDP 干扰，可减少缓冲。

游戏与低延迟链路

旗舰版含 IPLC 专线游戏加速优化，适合对抖动敏感的对战与登录。建议单独建立游戏规则，仅对游戏进程走专线，其他流量走普通节点或直连。

小团队协作

团队版提供 1000GB 月流量、20 台在线与定制路由，可按部门划分代理策略。专属客户经理用于节点变更与路由模板调整，而不是替代各成员自己的客户端配置。

操作说明

1. 选择套餐并保存订阅

在官网选定基础版、旗舰版或团队版后，账户中会生成订阅地址。请复制完整链接，不要通过聊天软件反复转发以免被截断。年付用户流量与设备规则与月付相同，仅计费周期不同。

2. 下载并安装客户端

回到客户端选择，按系统下载安装包。Windows 注意允许系统代理；macOS 与 iOS 需批准 VPN 配置描述文件；Android 需允许创建 VPN 连接。安装来源请使用本页给出的官方下载入口。

3. 导入订阅

打开客户端的订阅或配置页面，粘贴链接并更新。成功后应看到节点分组：普通线路、流媒体解锁、IPLC 游戏等。若列表为空，检查链接是否完整、本地时间是否准确，然后再次更新。

4. 选择模式并启用

推荐规则模式（Rule）：国内直连、跨境走代理。需要临时全站加速再改全局。启用系统代理或 VPN 开关后，用浏览器访问目标站点验证。游戏用户在旗舰版中指定 IPLC 组。

5. 日常维护

每周更新一次订阅以获取节点变更。流量将尽时减少 4K 播放或升级套餐。更换设备时先在旧设备断开，避免超过同时在线上限。问题优先通过工单描述客户端名称、系统版本与错误原文。

线路与加速说明

普通线路覆盖香港、新加坡、日本、美西等常用出口，适合网页与轻量办公。旗舰版在此基础上提供原生流媒体解锁与 IPLC 游戏优化；团队版另有高带宽 VIP 节点，适合多人同时拉取大文件。实际速度受本地宽带与运营商路由影响，建议在客户端内测延迟后收藏 2～3 条备用。

小机场把分流规则与节点更新放在订阅里，一般无需手工编辑配置。若企业需要固定出口或分部门策略，使用团队版的定制路由，而不是在每台电脑上维护不同文件。

常见问题

小机场是什么？和普通 VPN 软件有何不同？

小机场是机场订阅服务：你购买的是可更新的节点与规则，而不是单一封装的 VPN 客户端。同一订阅可导入多种加速器，便于在电脑与手机间切换。本站作为小机场官网，集中说明套餐、客户端下载与导入步骤。

应该怎样选择客户端？

Windows 优先 Clash Verge 或 v2rayN；macOS 可用 ClashX Meta；iOS 常用 Shadowrocket；Android 用 Clash Meta。先看设备系统，再看是否需要分应用代理。选定后从本页客户端章节进入对应官方下载，避免混用来源不明的修改版。

如何把机场订阅导入客户端？

复制账户中的订阅地址，在客户端选择“从 URL 更新”或“添加订阅”，粘贴后拉取节点。导入成功会出现分组列表。若失败，检查链接首尾空格、系统时间，并确认套餐仍在有效期内。详细顺序见操作说明。

基础版、旗舰版和团队版怎么选？

个人轻度使用、三台设备以内选基础版（100GB）。需要原生流媒体、五台设备和游戏 IPLC 选旗舰版（300GB）。公司或工作室多设备、大流量与定制路由选团队版（1000GB / 20 台）。年付价格已在各套餐中标明。

支持流媒体解锁和游戏加速吗？

基础版提供基础流媒体解锁；旗舰版为全节点原生流媒体解锁，并含 IPLC 专线游戏加速优化。播放或开游戏前请切换到对应分组，使用规则模式避免把所有流量打满专线。

流量用完或设备超限怎么办？

月度流量用尽后可等待重置或升级套餐。同时在线超过套餐台数时，新设备会连接失败，请在闲置设备上断开代理。团队版适合需要长期多终端在线的情况。

在哪里进行官方下载？安全吗？

客户端名称与入口集中在本页“客户端选择与官方下载”。请核对应用名后再安装，不要信任来路不明的“一键包”。小机场只提供订阅，客户端本身来自各项目的官方渠道。安装后只需导入你的订阅链接。
